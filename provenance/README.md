# LaTeX source provenance

The `tfpt-source/` directory preserves byte-identical historical TeX and PDFs from public source revision `ba2f0fc`, before the Prime Front extraction. It includes complete mixed TFPT papers so every moved claim can be checked in its original context; these historical copies are not current Prime Front assertions about physics.

`latex-source-manifest.json` records every archived source hash. `latex-section-map.json` records extracted section/paragraph spans, original labels and content hashes. Dedicated document filenames and module IDs are kept for traceability. `documents/extracted/*.tex` preserves extracted source text; the corresponding `.publication.tex` assemblies omit only presentation-box furniture so formerly embedded excerpts compile independently. Root `extracted_*.tex` files are their compilable wrappers.

Separation changes ownership, not any mathematical verdict. Finite/certified results, negative results, explicit hypotheses and open RH statements retain their original scope. The original German mixed report `big_picture_2026-08-02_de` is available as a historical archive only. Physics-specific E8/Gaussian/Hamming machinery stays with TFPT; its original snapshots here supply provenance for the arithmetic branch.
