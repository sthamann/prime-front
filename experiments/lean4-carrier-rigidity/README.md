# Prime Front formal support

This project maintains the transferred finite/conditional RH and prime statements under their original `TfptCarrier` namespace. The namespace is stable provenance, not a physical assumption. Dedicated modules and their original generic dependencies are present; the physical carrier/Yukawa/Standard Model project remains in TFPT.

Run `lake build TfptCarrier.CIRoot` for the core. Full `lake build` also includes the original heavy wall certificates; use the preserved serial wall build script where required. A fresh Lean build is distinct from source/import consistency or a Python module run.

Original mixed root/audit/ParityWeightLaws sources are preserved in `provenance/mixed-controls/`. No theorem is promoted to an RH proof.
